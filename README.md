# 🍰 Nidhi's Heavenly Dessert

A dessert-focused UI/UX design created in Figma.

## 🎨 Project Overview

Nidhi's Heavenly Dessert is a sweet and attractive dessert website designed to provide users with a simple and enjoyable browsing experience.

## ✨ Features

* 🏠 Home page
* 🍰 Dessert categories
* 🧁 Dessert product cards
* 🔍 Easy navigation
* 🛒 Product browsing
* 📱 User-friendly interface
* 🎨 Clean and attractive UI
* 🔗 Interactive Figma prototype

## 🛠️ Tools Used

* Figma
* UI/UX Design
* Wireframing
* Prototyping
